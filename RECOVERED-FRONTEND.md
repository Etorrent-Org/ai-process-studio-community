# Frontend source recovery

Version 1.0.0 was distributed with a compiled `dist/` tree but without its original maintainable frontend source.

Version 1.1.0 first restored a maintainable Vinext/Vite source baseline, then Lot C completed the transition to a clean Community source boundary.

Current Community state:

- `app/community-studio.tsx` is the maintained Community frontend;
- `app/page.tsx` imports only the Community frontend;
- Professional feature implementations are not present in the Community `app/` tree;
- Community prompt definitions are separated from proprietary Professional prompts;
- `dist/` is generated by `npm run build` and is not tracked by Git;
- Docker rebuilds `dist/` from the maintained Community source;
- the legacy `scripts/patch-legacy-ui.mjs` compatibility step has been removed.

The private repository history still contains earlier transitional artifacts. For that reason, public publication must use a clean Community snapshot with fresh Git history rather than changing the existing private repository visibility in place.
