# Support

AI Process Studio Community is maintained through the public GitHub repository.

## Before opening an issue

Please verify that you are using the latest published Community release and that Docker Desktop is running normally.

For installation or runtime problems, collect:

- AI Process Studio version
- Windows version
- Docker Desktop version
- exact command used
- exact error message
- relevant Docker logs with secrets removed

## Bugs

Use the repository's **Bug report** issue template. Keep the reproduction steps as short as possible and describe the expected and observed behaviour.

## Feature requests

Use the **Feature request** template. Start with the process or user problem rather than the implementation idea.

Community requests should fit the public `core`, `discover` and `map` scope. Professional capabilities are maintained in a separate commercial distribution.

## Security

Do not report exploitable vulnerabilities in a public issue. Follow `SECURITY.md` and use GitHub private security reporting when available.

## Sensitive data

Never attach passwords, session cookies, Professional signing keys, customer licence files, production `.env` files or private backup archives.
